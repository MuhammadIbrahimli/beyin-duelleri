## Что ещё не сделано

1. **Командные испытания** (командный матч между командами) и отдельный экран истории результатов команды.
2. **Выбор дисциплины** в битве городов (сейчас только средняя доля побед).
3. **Статус присутствия** друзей (в ТЗ необязательно, при реализации нужно уважать приватность).
4. **Таблицы лидеров по событиям** (сейчас событие меняет только множитель XP).
5. **Проверка на устройствах:** Safari, Android Chrome, PWA. Проверены только размеры экрана во встроенном браузере.
6. **Монетизация:** провайдеры рекламы и платежей. Без ключей и одобрения это сознательно выключено.
7. **Старые экраны:** настройки остаются на старом «Pasport», их не переносили в компактный раздел.

## Архитектурные решения (кратко)

- Матч — композиция существующих движков; раунды движков задаются при создании (по умолчанию как раньше).
- Очередь — один Durable Object `Queue`; комнаты в памяти Durable Object; результат пишется один раз (`ON CONFLICT DO NOTHING`).
- Рейтинг, награды и результаты считает сервер; клиент присылает только ходы и выборы.
- Журнал Qızıl и XP: каждая операция с уникальной ссылкой; дубликат откатывает батч; баланс не уходит в минус.
- День и неделя по Баку (UTC+4, без летнего времени).
- Квесты дня одинаковы для всех (один seed на день). Награды раз.
- Марафон: задания строит сервер из seed забега; правильный ответ клиенту не отправляется; время проверяет сервер.
- Города и командная неделя: среднее по игрокам, минимум матчей и игроков; смена города ограничена кулдауном.
- Сезоны и события — из конфига по дате; сезонная коррекция ленивая (при первом обращении в новом сезоне). Ничего не удаляется.
- Серии: награды за 3/7/14/30/60/100 дней; заработанное не отбирается при обрыве серии.
- Университеты: только из списка с сайта Министерства; неизвестное название отклоняется.
- Маршруты, которые используют `auth` подроутеров, подключены раньше них (иначе 401; найдено в e2e).
- Платежи и реклама выключены флагами.

## Известные ограничения и риски

1. **Комнаты и очередь в памяти Durable Object.** При деплое или выгрузке объекта текущий матч и очередь теряются; клиент показывает «соединение потеряно». Исправление: сохранять снимок комнаты.
2. **Рейтинг: чтение и запись без сравнения версий.** Два одновременных завершения матчей одного игрока теоретически могут перезаписать друг друга.
3. **Статистика начинается с новых матчей.** Старые матчи не пересчитывались.
4. **Загадки Марафона и дуэли на азербайджанском** в русском интерфейсе.
5. **Дружеский матч** открывается любому, у кого есть код; вызов другу — только двоим.
6. **Подозрительные матчи** помечаются флагом; очереди проверки нет.
7. **Задержка на медленной сети** может засчитывать реакцию как опоздание (запас 1.5 с).
8. **Университеты.** Названия взяты с официальных страниц (дата страниц 28.01.2026). Перед публичным запуском их нужно перепроверить: это зафиксировано в комментарии файла.
