# Beyin duelləri

Веб-приложение (PWA) на азербайджанском: мини-эксперимент за 60–90 секунд, карточка результата и дуэль с другом по ссылке.
Стек: TypeScript, Vite, Cloudflare Workers + Hono, Cloudflare D1. Требования и механика: `SPEC.md`.

## Запуск локально

Нужен Node 22+ (проверено на 24).

```bash
npm install
```

```bash
npm run db:migrate:local
```

```bash
npm run dev
```

Открой http://localhost:8787. `npm run dev` сам собирает фронтенд, создаёт `.dev.vars` с секретом сессий и запускает Worker с локальной D1.

| Действие | Команда |
| --- | --- |
| Тесты | `npm test` |
| Проверка типов | `npm run typecheck` |
| Фронтенд с горячей перезагрузкой (рядом с `npm run dev`) | `npm run dev:web` |
| Тестовые данные для рейтинга городов и процентилей | `npm run db:seed` |
| Пересчитать рейтинг и процентили (cron вручную, сервер должен работать) | `npm run db:cron` |
| Убрать тестовые данные | `npm run db:unseed` |
| Список всех `TODO(verify)` | `npm run todo` |

## Деплой на Cloudflare

Первый раз (создаёт D1, применяет миграции, собирает, деплоит, задаёт секрет сессий). Перед этим один раз `npx wrangler login`.

```bash
npm run setup
```

Все следующие разы (сборка, миграции, деплой):

```bash
npm run deploy
```

- Один Worker отдаёт и статику (`dist/`), и API (`/api/*`). Cron раз в час пересчитывает рейтинг городов и процентили.
- Ограничение частоты: Rate Limiting binding (120 запросов в минуту на хэш IP). IP нигде не хранится, хэш с солью, которая меняется каждые сутки.
- Короткий домен: подключи в панели Cloudflare, затем впиши его в `config/brand.ts` (для карточек) и, при желании, в `SITE_ORIGIN` в `wrangler.toml`. Пока `SITE_ORIGIN` пустой, ссылки дуэлей строятся от адреса запроса.
- Лимиты бесплатных тарифов: запросы на API лёгкие (несколько запросов к D1), тяжёлые агрегаты считает только cron, карточки рисует клиент.

## Структура

```
shared/      логика, общая для клиента и сервера: seed, баллы, уровни, дуэли, серия, валидность
worker/      Hono API, cron-агрегация, бейджи
src/         клиент: экраны, эксперименты (каждый грузится лениво), карточки на canvas
src/i18n/    все тексты интерфейса (az.ts)
src/tokens.css   дизайн-токены: цвета, шрифты, отступы (меняй здесь)
config/      данные, которые нужно проверить: источники, слова, факты, пороги, города
migrations/  схема D1
tests/       vitest
```

Сервер выдаёт seed и расписание задания, клиент присылает только времена и ответы, баллы и валидность считает сервер.

## Открытые решения

- Воскресенье («Həftənin duelu») сейчас использует Refleks, нужно выбрать эксперимент.
- «Eyni rəngdir?»: во всех трёх раундах пары равны, поэтому ответ «Ənə» три раза даёт 0 ошибок. Если хочешь честнее для рейтинга, добавим контрольную пару с настоящей разницей.
- «Şəhər duelu», платежи, Pro-версия, Telegram-бот: вне объёма MVP.
- Установка на экран (PWA) предлагается после второго пройденного теста там, где браузер поддерживает `beforeinstallprompt`. На iOS Safari вручную через «Поделиться».
